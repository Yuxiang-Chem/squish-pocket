# Project status

The browser prototype is published at https://squish.chemisgreat.online/ for public phone access. The browser source is in `browser/`; see its `VERIFICATION.md` for the browser checks.

For the native Swift project:

- 20 platform-independent checks passed, including 24,000 fixed simulation steps.
- The shared SwiftUI sources type-checked against the available macOS SDK.
- A Mac preview binary compiled successfully, but its visual review was interrupted and is not complete.
- Project, app Info.plist, and privacy manifest passed plist syntax validation.
- Full Xcode, the iOS SDK, the iPhone simulator, and device signing were unavailable. The native iPhone app has not been built or installed.

The browser version is the current playable deliverable. The native project is retained for later work.
