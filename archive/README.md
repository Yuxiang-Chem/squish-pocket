The earlier `/Users/chem/SquishPocket` folder was consolidated into this repository
on 2026-11-04. Its native source was identical; its browser game was older.

`SquishPocket-before-consolidation-2026-11-04.tar.gz` is a complete local snapshot,
including earlier release archives and native build files. All 605 regular files
were checked by SHA-256 against the archive before the duplicate folder was
replaced with a symlink to this repository. The local
`consolidation-manifest.json` records the archive and individual file hashes.

binding lives at `browser/.openai/hosting.json`, also ignored. Current source is
in the repository's normal directories; restore the archive elsewhere if needed.
